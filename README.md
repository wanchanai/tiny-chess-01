A chess engine in 3,023 bytes of Python (LZMA-packed from a readable source): negamax alpha-beta with a transposition table, PVS, LMR, quiescence, null-move pruning and MVV-LVA ordering. Deterministic: a fixed node budget per move. Practice gauntlet: 3 wins, 3 losses (about Elo 1280).

## Run it

```sh
MAKEFUN_ENV_URL=<game environment URL> python3 main.py
```
